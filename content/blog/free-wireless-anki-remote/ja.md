## 「Ankiリモート」で検索する人が本当に求めているもの

本格的にAnki復習をしている人なら、検索の流れは予想通りだ：手を空けたい。**トレッドミルで歩いている**とき、夜に仰向けに寝ているとき、エアロバイクに乗っているとき、あるいは単に復習セッション中ずっとスマホを握り続けるのにうんざりしているとき。キーボードを見たくない。流れを断ち切らずにカードをめくり、評価したい。

長い間、最善の答えはハードウェアだった。小さなBluetoothキーパッドを手に持ち、ボタンを押せば、デスクトップ版Ankiアプリがキー入力を認識し、カードがめくれる。それで完了だ。このハードウェア＝キーボードというパターンこそ、医学部生のAnkiコミュニティで<a href="https://studyremote.com/" rel="nofollow">StudyRemote</a>や様々な<a href="https://www.theanking.com/controller" rel="nofollow">8BitDo</a>セットアップが人気を博した理由である。

変わったこと：ほとんどの人がすでに、ポケットに完全に使えるワイヤレスリモートを入れている — 自分のスマホだ。それをリモートに変えるソフトウェアが必要だっただけだ。

## 既存の選択肢：簡単に

### StudyRemote（専用ハードウェア）

もともとはKickstarter（当時の名称は「Anki Remote」）で資金調達された<a href="https://studyremote.com/" rel="nofollow">StudyRemote</a>は、5つの大きめのボタンを備えた小さなくさび形のBluetoothキーパッドだ。電源を入れ、Bluetoothキーボードとしてペアリングすれば、Ankiがそのキーストローク（1, 2, 3, 4, スペース, アンドゥ）を認識する。価格は約**$40-60**。30,000人以上のユーザーがいると主張しており、製品は実在し動作する。

ハードウェアを支持する理由：触覚フィードバック、絶対に押し間違えない専用ボタン、何も見る必要がない。完全に「平らに寝て、電気を消し、見ないで復習する」というユースケースには、正直なところ専用ハードウェアに勝るものはない。

反対する理由：また$60のデバイスが増え、紛失する可能性のあるものが増え、充電すべきバッテリーが増える。

### 8BitDo回避策

小さなゲームコントローラーを製造する8BitDo — 特に有名なのは**Zero 2**と**micro** — は、Anki復習のためのコミュニティのお気に入りとなっている。価格は$20-30、ポケットにも入るサイズで、フェイスボタンを評価ボタンに割り当てられる。AnKingが<a href="https://www.theanking.com/controller" rel="nofollow">推奨セットアップ</a>を公開しており、YouTubeには視聴回数80,000回のバイラルチュートリアルがあり、<a href="https://ankiweb.net/shared/info/1898790263" rel="nofollow">Contanki</a>はデスクトップ版Ankiアドオンのデファクトスタンダードである。

しかし、ほとんど誰も話さないiOS側の大きな注意点がある：**AnkiMobile（公式iOS版Ankiアプリ）は、それらの小さな8BitDoコントローラーをゲームパッドモードで受け付けない。** AnkiMobileはAppleの`GCExtendedGamepad`プロファイルのみをリッスンしており、Zero 2やmicroはこれを公開しない。つまり、人々が*Ankiのために*特別に買う安価で人気のコントローラーは、デスクトップでは完璧に動作するが、iPhoneでは動作しないのだ。

### Contanki / Ankimote（Ankiアドオン）

どちらも、Anki Desktopエコシステムの中に留まるなら優れた選択肢だ。特にContankiは洗練されたアドオンで、インストールし、コントローラーを接続し、マッピングを設定するだけだ。iPhoneを経由させる必要がなければ、これは素晴らしい無料の選択肢である。

## スマホをリモートとして使う選択肢

これが私たちが作ったものだ。<a href="/ja/anki-remote">Flashcard Guru Remote</a>は、小さなAnki Desktopアドオン（オープンソース、LGPL-3.0）で、<a href="/ja/">Guru iOSアプリ</a>とWi-Fi経由でペアリングする。iPhoneがリモートになる：画面上で*答えを表示*を押せば、デスクトップのカードがめくれる。*Good*を押せば、カードがスケジュールされ、次のカードに進む。

これが既存の選択肢と重複しない理由は二つある：

1. **無料で、すでに持っているハードウェアを使う。** iPhoneを持っているなら、これを試すのに$60のキーパッドは必要ない。（最終的にハードウェアを好むかどうかは別問題だ — 以下の正直な比較を参照。）
2. **電話機を経由して安価な8BitDoコントローラーを橋渡しできる。** Zero 2やmicroをUSB-C/Lightning経由でiPhoneに接続するか、Bluetoothでペアリングする。Guru iOSアプリは、Appleの`GCExtendedGamepad`プロファイル*と*`GCKeyboard`イベントの両方をリッスンする — 後者は8BitDoの「キーボードモード」が生成するものだ。コントローラーのボタンを押せば、iPhoneがそのアクションをAnki Desktopに転送する。**AnkiMobileが拒否するまさにそのコントローラーが突然動作する。なぜならGuruアプリが間に立つからだ。**

## iPhoneにAnkiリモートを接続する方法（60秒）

これがスマホ-リモートルートの全セットアップ手順だ。スクリーンショット付きの完全なウォークスルーは<a href="/ja/anki-remote">Anki Remoteセットアップページ</a>にある。ここでは短縮版を紹介する：

1. **Macで：** Ankiを開き、`ツール → アドオン → アドオンを取得…` を選び、次のコードを貼り付ける：
   <p><code style="font-size: 1.05em; padding: 4px 10px;">1196082853</code></p>
   Ankiを再起動する。アドオンが初回起動時に、macOSが*"受信接続を許可しますか？"*と尋ねてくるので — **許可**をクリックする。
2. **iPhoneで：** App Storeから<a href="https://apps.apple.com/app/flashcardguru/id6757980593">Guru</a>をインストールする。
3. **ペアリング：** Anki Desktopで、`ツール → 電話を接続 (Flashcard Guru Remote)…` を選ぶ。QRコードが表示される。Guruを開き、`設定 → Anki Remote → Macとペアリング` を選び、スキャンする。完了。

Macで任意のデッキを開けば、iPhoneの画面が復習を引き継ぐ。答えを表示、Again、Hard、Good、Easy、音声の再生、アンドゥ — すべて可能だ。状態の更新はリアルタイムで電話機にフィードバックされるため、表示されるボタンは常に現在のカードに対応する。両方のデバイスが**同じWi-Fiネットワーク**上にある必要がある — クラウドアカウントやケーブルは不要だ。

## iPadでも動作しますか？

はい。Guruはユニバーサルアプリなので、同じリモート機能がiPhoneだけでなくiPadでも動作する — Macの横にスタンドに置いたiPadがある場合に便利だ。ペアリングの流れは同一：デスクトップにアドオンをインストールし、iPadからQRコードをスキャンすれば、タブレットが復習をコントロールする。（特にiPadでAnkiリモートを使う方法を探しているなら、これが答えだ — 同じWebSocketブリッジで、追加のセットアップは不要だ。）

## ハンズフリーAnki復習：トレッドミル、横になっているとき、暗闇で

「ハンズフリーAnki」は実際には二つの異なる意味を持ち、区別する価値がある：

- **一瞥してタップ。** 電話機を立てかけたり片手で持ったりして、大きく表示された*Again / Hard / Good / Easy*ボタンを見てタップする。ソファ、机、画面が見えるエアロバイクなどに最適。
- **見ないで。** 目を閉じて、電気を消して、またはトレッドミルで下を向くのが難しい場合。ここでは触覚ボタンが勝る — そしてまさにそのために以下の8BitDoブリッジがある。

ほとんどの机とソファでの復習には、電話機での一瞥タップで事足りる。厳格なノールック復習には、コントローラーをブリッジ（次のセクション）すれば、専用キーパッドを買わずに物理ボタンを手に入れられる。

## 安価な8BitDo（Zero 2 / micro）を電話機経由で使う

これは他に存在しない部分だ。**8BitDo Zero 2**または**micro**をiPhoneとペアリングする — Bluetooth経由、またはUSB-C経由の有線接続 — そしてコントローラーを**キーボードモード**にする。Guruアプリはそれらの`GCKeyboard`イベントを読み取り、対応する復習アクションをAnki Desktopに転送する：

- `1 / 2 / 3 / 4` → Again / Hard / Good / Easy
- `スペース` → 答えを表示 · `R` → 再生 · `Z` または `U` → アンドゥ

Ankiと通信しているデバイスは*電話機*なので、AnkiMobileが完全にペアリングを拒否するコントローラーでもここでは問題なく動作する。約$25で触覚的なノールックボタンを手に入れられ、$60の専用リモートは不要で、コントローラーを持っていないときは電話機だけで復習することもできる。

## 正直な比較

| | StudyRemote | 8BitDo + Contanki | iPhone + Flashcard Guru Remote |
|---|---|---|---|
| コスト | ハードウェア$40-60 | ハードウェア$20-30 | 無料（自分の電話機を使用） |
| ノールック操作性 | ★★★（触覚的、専用） | ★★★（触覚的、専用） | ★★（画面を一瞥、コントローラーをブリッジしない限り） |
| オープンソース | いいえ | はい（Contankiアドオン） | はい（LGPL-3.0アドオン） |
| 安価な8BitDo（Zero 2 / micro） | 該当なし | はい（Anki Desktopのみ） | はい — iPhone経由でデスクトップでも |
| AnkiMobileとの互換性 | はい（HIDキーボード） | いいえ、小型モデルでは | 別のiOSアプリとの連携 |
| プライバシー | ローカルBluetooth | ローカルUSB / BT | LANのみ、トークンペアリング |

正直な評価：**厳格なノールック復習を多く行う場合**（トレッドマル、目を閉じて、暗闇で）、専用ハードウェアが依然として勝る。親指の下にある触覚ボタンに勝るものはないからだ。**復習のほとんどを机やソファで、iPhoneがすでに手の届く範囲にある状態で行う場合**、スマホ-リモートは価格の0%でユースケースの90%をカバーする — さらにZero 2も持っていれば、それを電話機にペアリングしておまけとしてノールック操作性を取り戻せる。

## なぜネイティブBluetoothキーボードエミュレーションではなく電話機なのか？

「iPhoneが単にMacが見るBluetoothキーボードとして振る舞えば、もっとすっきりするのでは？」という明白な疑問がある。その答えはプラットフォームレベルにある：**iOSはサードパーティアプリがBluetooth HIDペリフェラルとして動作することを許可していない。** これは特定のアプリの機能不足ではなく、Appleが10年間ずっと保持している制限だ。そこで、次善の策 — 既存のWi-Fiを介した小さなWebSocket接続 — を使う。これはエンドユーザー体験が同じで、さらに構造化された状態更新（iPhoneは常にどのデッキにいて、どのキューにいて、どのフェーズにいるかを把握している）をサポートするという利点もある。

## プライバシー：簡単に

ペアリングトークンはローカルネットワークを離れることはない。アドオンは安全チェックとしてRFC-1918 / ループバック / リンクローカルIPからの接続のみを受け入れるため、誤ってポートをパブリックインターネットに公開したとしても、サーバーはハンドシェイクを拒否する。分析、リモートログ、「ホームコール」は一切ない。AnkiデスクトップのダイアログからペアリングしたiPhoneをいつでも取り消すことができ、トークンは即座に無効になる。

## まずは「ハンズフリー」を定義しよう

「ハンズフリー anki」で検索する人の状況は意外なほど異なり、適切なセットアップはあなたがどのケースに当てはまるかで決まります：

- **チラ見＆タップ。** スマホを立てかけたり、片手で軽く持っている状態。カードは見えていて、単にキーボードに縛られたくないだけ。画面上の大きな *Again / Hard / Good / Easy* ボタンで十分です。
- **ノールック。** トレッドミル・暗いベッド・エアロバイクで——下を向いてボタンを探すことがそもそも問題。ここで必要なのは、見なくても押せる**触覚**ボタン。

「ハンズフリーAnkiが欲しい」という人の大半はチラ見＆タップです。ノールックこそがハードウェアの真価を発揮するケースです。

## セットアップ1：デスクトップAnkiのリモコンとしてスマホを使う

実際の復習を**デスクトップAnki**で行い、キーボードから離れたいだけなら、iPhoneをワイヤレスリモコンに変身させましょう。<a href="/ja/anki-remote">Guru Anki Remote</a>はスマホをWi-Fi経由でデスクトップAnkiとペアリングし（QRコードで約1分）、画面上に*Show Answer / Again / Hard / Good / Easy / Replay / Undo*を表示します。カードの状態はリアルタイムで同期されるので、ボタンは常に今のカードに対応します。

これは部屋の向こう側から行うチラ見＆タップ——ソファやスタンディングデスクに最適です。詳細はこちら：<a href="/ja/blog/free-wireless-anki-remote/">無料ワイヤレスAnkiリモートガイド</a>。

## セットアップ2：真のノールックにコントローラーを追加

目を閉じての復習やトレッドミル学習には、小型ゲームコントローラーを追加して、触感でボタンを押せるようにしましょう。ポケットサイズの**8BitDo Zero 2またはmicro**（20～30ドル）がコミュニティで人気です。ボタン割り当て：

- `1 / 2 / 3 / 4` → Again / Hard / Good / Easy
- `Space` → Show Answer

デスクトップAnkiではContankiで設定可能。AnkiMobileが拒否する安価モデルを*iPhone経由*で使うには、Guru Anki Remoteのキーボードモード対応で橋渡しします。手順：<a href="/ja/blog/8bitdo-anki-setup/">8BitDoのAnki設定</a>。

## 人間工学のヒント

- **評価手の位置を固定する。** コントローラーでもスマホでも、親指のホームポジションを一定に保ち、見ずに評価できるようにしましょう。
- **音声再生をオンにする。** 語学や医学デッキの場合、Replayボタンがあれば完全に画面から目を離せます。
- **短いセッションに分割する。** ハンズフリーは、一日に5〜10分の短いバーストで期限切れカードを片付けるのに最適。長時間のマラソンセッションには向いていません。

## FAQ

**スマホだけで完全ハンズフリーは可能ですか？**
チラ見＆タップなら可能です。厳密な目を閉じた復習には、触覚コントローラーが必要です——画面では感触で見つけられるボタンを提供できません。

**AnkiMobileでも使えますか？**
スマホリモコン機能と8BitDoブリッジは、別のiOSアプリ「Guru」の機能で、**デスクトップAnki**を操作します。AnkiMobile独自の（より制限された）コントローラーサポートもあります。

**音声コントロールは使えますか？**
高速復習には信頼性が不十分です。ボタンやタップの「押して次へ」ループの方が、毎カード評価を声に出して言うより速くて静かです。

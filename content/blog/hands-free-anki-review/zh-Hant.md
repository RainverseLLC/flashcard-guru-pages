## 首先，定義「免手持」

人們搜尋「hands free anki」的背後情境其實差異很大，正確的設定取決於你屬於哪一種：

- **看一眼就點。** 手機架在一旁或鬆鬆地拿在手上。你看得到卡片，只是不想被鍵盤綁住。螢幕上大大的 *Again / Hard / Good / Easy* 按鈕就夠了。
- **完全不看。** 你在跑步機上、關燈躺在床上、或騎飛輪車——低頭找按鍵本身就是問題所在。這時你需要的是不需要看就能按的**觸感按鍵**。

大部分「我想要免手持 Anki」的情況屬於「看一眼就點」。只有「完全不看」的場合才需要硬體來發揮價值。

## 設定 1：把手機當作桌機 Anki 的遙控器

如果你真正的複習是在**桌機版 Anki** 上進行，只想離開鍵盤，就把你的 iPhone 變成無線遙控器。<a href="/zh-Hant/anki-remote">Guru Anki Remote</a> 透過 Wi-Fi（QR Code，約 1 分鐘）將手機與桌機版 Anki 配對，並提供螢幕上的 *Show Answer / Again / Hard / Good / Easy / Replay / Undo*。卡片狀態會即時同步回去，所以按鈕永遠對應到你正在看的卡片。

這適用於在房間另一端「看一眼就點」——非常適合沙發或站立辦公桌。完整背景介紹：<a href="/zh-Hant/blog/free-wireless-anki-remote/">免費無線 Anki 遙控器指南</a>。

## 設定 2：用控制器達到真正的「完全不看」

要閉眼複習或在跑步機上使用，加上一個小遊戲手把就能靠觸感按按鍵。口袋大小的 **8BitDo Zero 2 或 micro**（20-30 美元）是社群最愛。按鍵對應：

- `1 / 2 / 3 / 4` → Again / Hard / Good / Easy
- `Space` → Show Answer

在桌機版 Anki 上，你可以用 Contanki 設定；如果想讓便宜的型號**透過你的 iPhone** 使用（那些 AnkiMobile 不支援的），就用 Guru Anki Remote 的 Keyboard Mode 支援橋接。逐步教學：<a href="/zh-Hant/blog/8bitdo-anki-setup/">8BitDo 設定 Anki</a>。

## 人體工學小技巧

- **固定你的評分手勢。** 無論是用控制器還是手機，讓拇指的起始位置保持一致，這樣你才能不看就評分。
- **開啟音訊重播。** 對於語言或醫學牌組，一個 Replay 按鈕讓你可以完全不用看螢幕。
- **分批進行短時段複習。** 免手持最適合在一天中用 5-10 分鐘的短時間清除到期卡片，而不是長時間馬拉松。

## 常見問題

**光靠手機就能真正做到完全免手持嗎？**
如果是「看一眼就點」，可以。如果是嚴格的閉眼複習，你需要一個觸感控制器——螢幕無法提供你靠觸覺找到的按鍵。

**這能在 AnkiMobile 上運作嗎？**
手機當遙控器和 8BitDo 橋接功能是 Guru（一款獨立的 iOS App）的一部分——它們驅動的是**桌機版 Anki**。AnkiMobile 有自己的（支援度較低）控制器支援。

**語音控制可行嗎？**
對於快速複習來說並不可靠——按一下或點一下的循環比對每張卡片說出評分更快、也更安靜。

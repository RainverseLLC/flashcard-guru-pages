## 첫째, '손이 자유롭다'는 것을 정의하자

사람들이 "hands free anki"를 검색하는 상황은 놀랍게도 각기 다릅니다. 올바른 설정은 자신이 어떤 상황에 있는지에 따라 달라집니다:

- **잠깐 보면서 탭하기.** 폰을 거치해 놓거나 한 손에 느슨하게 쥐고 있습니다. 카드는 볼 수 있고, 키보드에 매여 있고 싶지 않을 뿐입니다. 화면에 큰 *Again / Hard / Good / Easy* 버튼이면 충분합니다.
- **보지 않고 하기.** 런닝머신 위에 있거나, 불을 끈 침대에 누워 있거나, 실내 자전거를 타고 있을 때 — 버튼을 찾으려고 고개를 숙이는 것 자체가 문제입니다. 이럴 때는 **촉각** 버튼이 필요합니다. 보지 않고 누를 수 있어야 하거든요.

대부분의 "손이 자유로운 앙키(Anki)를 원해요"라는 경우는 '잠깐 보면서 탭하기'에 해당합니다. '보지 않고 하기'는 하드웨어가 진가를 발휘하는 경우입니다.

## 설정 1: 데스크탑 앙키를 위한 폰 리모컨

실제 복습은 **데스크탑 앙키(Anki)**로 하고, 키보드에서 잠시 벗어나고 싶다면 아이폰을 무선 리모컨으로 바꿔보세요. <a href="/ko/anki-remote">Guru Anki Remote</a>는 폰과 데스크탑 앙키를 Wi-Fi(QR 코드, 약 1분 소요)로 연결해주고, 화면에 *Show Answer / Again / Hard / Good / Easy / Replay / Undo* 버튼을 제공합니다. 카드 상태는 실시간으로 동기화되어 버튼이 항상 현재 카드와 일치합니다.

이것은 방 건너편에서 '잠깐 보면서 탭하기'를 하는 것입니다 — 소파나 스탠딩 데스크에 완벽합니다. 자세한 내용은 <a href="/ko/blog/free-wireless-anki-remote/">무선 앙키 리모컨 무료 가이드</a>를 참고하세요.

## 설정 2: 진짜 '보지 않고 하기'를 위한 컨트롤러

눈을 감고 복습하거나 런닝머신 위에서 복습하려면 작은 게임 컨트롤러를 추가해서 버튼을 촉감으로 누르세요. 주머니에 쏙 들어가는 **8BitDo Zero 2 또는 micro** ($20-30)가 커뮤니티에서 가장 인기 있습니다. 버튼 매핑:

- `1 / 2 / 3 / 4` → Again / Hard / Good / Easy
- `Space` → Show Answer

데스크탑 앙키(Anki)에서는 Contanki로 연결할 수 있습니다. 저렴한 모델을 *아이폰을 통해* 사용하려면(AnkiMobile이 거부하는 모델들), Guru Anki Remote의 Keyboard Mode 지원을 통해 연결하세요. 단계별 가이드: <a href="/ko/blog/8bitdo-anki-setup/">Anki를 위한 8BitDo 설정</a>.

## 인체공학 팁

- **평가하는 손 위치를 고정하세요.** 컨트롤러든 폰이든, 엄지 손가락의 기본 위치를 일정하게 유지하면 보지 않고도 평가할 수 있습니다.
- **오디오 재생을 켜세요.** 언어나 의학 덱의 경우 Replay 버튼을 사용하면 화면에서 눈을 완전히 뗄 수 있습니다.
- **짧은 세션으로 나누세요.** 손이 자유로운 방식은 하루 종일 5-10분 단위로 밀린 카드를 처리할 때 빛을 발하며, 장시간 마라톤 세션에는 적합하지 않습니다.

## FAQ

**폰 하나만으로 완전히 손이 자유롭게 할 수 있나요?**
잠깐 보면서 탭하기에는 가능합니다. 엄격하게 눈을 감고 복습해야 한다면 촉각 컨트롤러가 필요합니다 — 화면은 촉감으로 찾을 수 있는 버튼을 제공할 수 없습니다.

**이 방법이 AnkiMobile에서도 작동하나요?**
폰-리모컨 기능과 8BitDo 연결 기능은 별도의 iOS 앱인 Guru의 일부로, **데스크탑 앙키(Anki)**를 제어합니다. AnkiMobile은 자체적인 (더 제한적인) 컨트롤러 지원 기능을 가지고 있습니다.

**음성 제어도 가능한가요?**
빠른 복습에는 신뢰할 수 없습니다 — 버튼이나 탭으로 하는 '눌러서 바로 다음' 루프가 모든 카드에 대해 말로 평가하는 것보다 더 빠르고 조용합니다.
